## README

Thanks for taking a look at SpiritBoardRebalance! One of the changes this mod does is revamp the drop rates and loot pool for each enemy. 

This removes Treats from the loot pool and instead boosts item and synth material rates. 

Enemies now only drop one type of orb, instead of randomly dropping between three types. This should make farming munny or drop orbs more standardized, like in other Kingdom Hearts games.

Enemies also drop the synth materials required for their corresponding recipe. 

Lastly, item rates and types have been adjusted to promote item use. Since you'll be going through each Dream Eater much quickly, there's no better way to build Links other than using Dream Candies or Elixirs!
